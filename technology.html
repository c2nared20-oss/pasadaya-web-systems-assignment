Technology

What's under the hood

PasaDaya is built with a mobile-first stack, a lightweight backend, and real-time services for location and communication.

Frontend

Flutter & Dart

A single cross-platform codebase powers both the Passenger and Driver mobile apps, ensuring a consistent experience on Android.

Backend

PHP REST API

A custom PHP API handles authentication, ride matching, and data exchange between both apps and the admin dashboard.

Database

MySQL

Structured relational storage for users, rides, fares, and driver verification records.

Real-time

Voice Calling SDK

In-app voice calls between passenger and driver run over a dedicated real-time communication service.

Location

GPS & Geocoding

Live device GPS combined with a geocoding service turns coordinates into readable addresses for both apps.

Hosting

Docker + Cloud Hosting

The backend API is containerized and deployed to the cloud, keeping the system online and reachable from anywhere.

Admin Panel

HTML, CSS & JavaScript

The web-based Admin Dashboard is built with the same core web technologies used in this assignment — no framework required.

Security

Role-Based Access

Separate authentication flows and permission checks for passengers, drivers, and municipal admins.
